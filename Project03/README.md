# 물 마시기 프로젝트

## 파일 구조

- **water_camera.py**: YOLO 컵 탐지, 사라짐·복귀 판정, 횟수 계산 및 JSON 저장 코드
- **water_assistant.py**: JSON 읽기, Gemma 설명 생성, 음성 질문 인식 및 음성 출력 코드
- **README.md**: 프로그램 설명 및 실행 방법
- **src/json/water_vision_data.json**: 현재 탐지 결과와 목표 횟수·진행 상황을 전달하는 파일. 실행 중 자동 생성
- **src/audio/**: 질문 녹음 파일과 응답 음성 파일을 저장하는 폴더

## 실행 방식

필요한 라이브러리 및 도구: OpenCV, Ultralytics YOLO, llama-cpp-python, Whisper.cpp, Piper, arecord, aplay

YOLO TensorRT 엔진, Gemma GGUF, Whisper 모델, Piper 한국어 음성 모델을 준비해야 합니다.

두 Python 파일은 `Project03` 폴더에 함께 놓습니다. 코드에서는 두 파일이 있는 폴더의 한 단계 위를 기준으로 `src`, `whisper.cpp`, `.piper_venv`를 찾습니다.

```text
Vision-LLM-202235079/
├── src/
├── whisper.cpp/
├── .piper_venv/
└── Project03/
    ├── water_camera.py
    ├── water_assistant.py
    └── README.md
```

1. 두 파일 상단의 모델 경로를 확인하고, `water_camera.py`의 `pipeline`을 사용하는 카메라에 맞게 설정합니다.
2. `arecord -l`로 마이크 번호를 확인하고, `water_assistant.py`의 `MIC_DEVICE`를 수정합니다.
3. 터미널 두 개에서 `Project03` 폴더로 이동하고 Python 가상환경을 활성화합니다.
4. `python water_assistant.py`를 실행하고 JSON 입력 대기 문구가 나올 때까지 기다립니다.
5. 다른 터미널에서 `python water_camera.py`를 실행하고 목표 횟수를 양의 정수로 입력합니다.
6. 컵받침 위에 컵 하나를 약 2초 동안 고정해 기준을 설정합니다. 이후 컵을 화면 밖으로 들었다가 원래 위치에 내려놓으며 횟수를 확인합니다.

영상 창을 선택한 상태에서 영문 `v`를 누르면 음성 질문을 요청할 수 있습니다. “말씀을 시작해 주세요”라는 안내가 끝난 뒤 5초 동안 질문하면 됩니다.

`r`은 현재 횟수를 유지한 채 컵의 기준을 다시 설정하고, `q`는 카메라 프로그램을 종료합니다. 음성 안내 프로그램은 해당 터미널에서 `Ctrl+C`로 종료합니다.

## 창의성 및 확장성

### 아이디어

충분한 수분 섭취는 건강을 유지하는 데 중요하며, 성인의 하루 물 섭취량으로는 일반적으로 약 1.5~2L가 안내됩니다.

평소 제가 물을 너무 적게 마시는 것 같아, 물 마시는 습관을 만들어 보고자 이 프로그램을 제작했습니다. 마신 횟수를 기록하고 목표를 달성하는 퀘스트 요소를 더해, 물을 꾸준히 마시는 데 재미를 느낄 수 있도록 구성했습니다.

YOLO와 Gemma를 연결하고, 사용자가 “몇 번 남았어?”라고 질문하면 현재 진행 상황을 음성으로 알려주도록 구성했습니다.

### 구현한 내용

시작할 때 가장 크게 검출되는 컵의 좌표를 일정 시간 모아 기준 면적과 위치를 정합니다. 컵이 0.8초 이상 검출되지 않은 뒤, 기준 면적의 80~120% 범위와 원래 위치 근처에서 다시 0.8초 이상 검출되면 1회로 기록합니다. 목표에 도달하면 화면에 완료 문구를 표시하고 Gemma가 생성한 설명을 음성으로 출력합니다.

영상 처리와 음성·Gemma 처리는 두 프로그램으로 나누었습니다. 카메라 프로그램은 0.2초가 지나거나 컵 상태·횟수·질문 요청이 바뀌면 JSON을 갱신하고, 안내 프로그램은 해당 파일의 변경을 확인합니다. Gemma가 응답을 생성하거나 질문을 녹음하는 동안에도 카메라 프로그램은 별도로 동작합니다.

### 확장성

일정 시간 동안 컵을 들지 않으면 알림을 주거나, 목표 횟수를 음성으로 설정하는 기능을 추가할 수 있습니다.

투명한 컵을 사용해 물 표면의 높이 변화를 분석하거나, 컵받침에 무게 센서를 부착해 컵을 들기 전과 내려놓은 후의 무게 차이를 측정하면 줄어든 물의 양을 추정해 기록할 수도 있습니다.

손이나 얼굴 인식을 함께 활용하여 컵을 입에 가져가는 동작까지 확인하는 방향으로 확장할 수도 있습니다.

## 기타 참고 사항

### 작업 중 고려한 점

컵이 잠깐 가려지거나 탐지 결과가 흔들릴 수 있어, 한 프레임에서 검출되지 않았다는 이유만으로 횟수를 올리지 않도록 했습니다. 컵이 카메라에 가까워져 크기만 달라진 경우에도 사라진 것으로 처리하지 않습니다.

### AI 활용 및 본인 기여

물을 마시는 동작을 퀘스트로 기록하는 아이디어는 제가 구상했습니다. 목표 횟수와 컵의 크기 기준, 화면에서 사라졌다가 돌아오면 1회로 기록하는 주요 동작 방식도 직접 정했습니다.

구현할 때에는 주피터노트북의 YOLO 탐지, Gemma 연동, STT·TTS 예제 코드를 최대한 그대로 활용하는 것을 기본 방향으로 삼았습니다. 각 코드의 역할과 실행 흐름을 확인하면서 프로젝트에 맞게 연결하고, 불필요한 부분은 줄이도록 수정 방향을 정했습니다.

코드를 연결하면서 막히는 부분이나 이해하기 어려운 문법은 ChatGPT의 설명과 수정 예시를 참고했습니다. 제안된 코드는 수업 예제와 비교하며 검토했습니다. README의 문장과 형식을 다듬는 과정에도 도움을 받았습니다.

### 추가 설명

처음 컵받침에 놓인 컵의 위치를 기준으로 사용하며, 컵받침 자체를 인식하지는 않습니다. 카메라와 컵받침의 위치를 고정하고 컵 하나를 사용하는 것을 기준으로 작성했습니다. 기록한 횟수는 컵의 사라짐·복귀 횟수이며, 실제 물 섭취 여부나 섭취량을 의미하지는 않습니다.

JSON은 현재 상태로 계속 갱신되는 전달용 파일입니다. 안내 프로그램은 가장 최근에 읽은 내용을 사용하며, Gemma는 프로그램이 계산한 횟수와 진행 상황을 문장으로 설명합니다.
