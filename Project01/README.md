# 손 동작 인식 가위바위보

## 파일 구조

- **rock_paper_scissors.py**: 손 인식, 가위바위보 판정 및 결과 이미지 저장 코드
- **README.md**: 프로그램 설명 및 실행 방법
- **hand_landmarker.task**: 손 인식 모델 파일 (`src/models/MediaPipe/`에 위치)
- **saved_images/**: 결과 이미지 저장 폴더. 처음 저장할 때 자동 생성

## 실행 방식

필요한 라이브러리: OpenCV, NumPy, MediaPipe

macOS의 Python 3.10.12와 `.venv` 환경에서 개발하고 실행을 확인했습니다. 학교에서는 Jetson 환경에 맞게 카메라 연결 부분을 변경하여 실행합니다.

1. Jetson의 VS Code에서 프로젝트 폴더와 `rock_paper_scissors.py`를 엽니다.
2. 카메라 연결 부분에 수업에서 사용한 Jetson용 코드를 적용합니다. (wjrdyddhksfy)
3. 준비된 `.venv`를 선택하고 프로그램을 실행합니다.
4. 카메라에 두 사람이 한 손씩 보여주고 결과를 확인합니다.

영상 창을 선택한 상태에서 영문 `q`를 누르면 종료되고, `s`를 누르면 결과 화면이 저장됩니다.

모델 파일은 `src/models/MediaPipe/hand_landmarker.task`에 있어야 하며, 터미널의 현재 위치는 `src` 폴더가 있는 프로젝트 최상위 폴더여야 합니다.

## 창의성 및 확장성

### 아이디어

수업의 `Detecting hand.py`와 `Counting Fingers.py`를 변형하여 두 손의 가위바위보 결과를 판정하는 프로그램을 만들었습니다. 손가락 개수만 출력하는 것에서 더 나아가, 두 손의 모양을 비교하여 누가 이겼는지 보여주도록 만들었습니다.

또한 실시간으로 지나가는 게임 결과를 사진으로 남기고 싶어, `s`를 누르면 손 모양과 승패가 표시된 화면을 저장하도록 만들었습니다.

### 구현한 내용

각 손 위에 손 모양을 표시하고, 승자는 초록색, 패자는 빨간색으로 나타냈습니다. 무승부나 판정 불가 상태는 노란색으로 표시하며, 상단에는 승패 문구를 표시합니다.

손목의 x좌표로 화면 왼쪽과 오른쪽을 구분했습니다. `s`를 누르면 손 모양과 승패 글씨가 포함된 화면을 `saved_images` 폴더에 저장하며, 파일 이름에는 저장 시각을 사용했습니다.

### 확장성

승리 횟수를 누적해 점수를 표시하거나, 저장한 사진을 Matplotlib으로 모아 보여주는 기능을 추가할 수 있습니다.

## 기타 참고 사항

### 작업 중 경험한 문제점

Jetson용 카메라 코드를 맥용으로 변경하고, 누락된 손 인식 모델 파일을 지정된 경로에 준비하여 실행 오류를 해결했습니다.

사진에 결과 글씨가 저장되지 않는 문제는 모든 글씨를 그린 뒤 저장하도록 코드 순서를 바꿔 해결했습니다.

### AI 활용

아이디어와 판정 규칙, 화면 구성은 제가 정하고, 수업 코드를 바탕으로 단계별로 수정하며 실행 결과를 직접 확인했습니다.

ChatGPT를 활용하여 실행 환경 설정, 코드 수정 예시, 문법 설명과 오류 검토에 도움을 받았습니다. 특히 사진 저장 함수를 만들면서 `pathlib`, `datetime`, `cv2.imwrite()`의 사용법을 설명받았습니다. README.md의 문장과 형식을 다듬는 과정에도 도움을 받았습니다.

### 추가 설명

엄지를 검지 옆에 붙여 주먹이나 가위를 만들면 엄지가 펴진 손가락으로 추가 계산되는 경우가 있었습니다. 이를 보완하기 위해 0개와 1개는 바위, 2개와 3개는 가위, 5개는 보자기로 처리했습니다. 4개는 Unknown으로 처리합니다.

사람을 따로 인식하는 것이 아니라 손 개수를 플레이어 수로 사용합니다. 따라서 한 사람이 두 손을 내도 두 명으로 표시됩니다. 또한 화면 위치로 좌우를 구분하므로 두 손이 교차하면 참가자의 좌우가 바뀔 수 있습니다.
